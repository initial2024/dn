未启用，不生成标识

标识由浏览器本地安全随机数生成，仅存放在本站 localStorage；不会作为请求参数、Cookie 或请求头发送，也不会上传服务器。启用后，导出的 JSON 报告将包含完整标识；关闭会删除本地标识并清除本地已存报告中的关联字段。它不证明同一物理设备，浏览器清理数据、隐私模式或 WebView 沙箱会使标识失效。

隐私选项在新浏览器内默认全部关闭；此前明确启用的本地访客标识会保留至手动撤销。点击基础检测会请求自有后端的网络摘要；不会发送完整 JS 采集结果。

状态判定说明

PASS 当前检测项的可观察 API 行为符合定义，不代表可信硬件或沙箱安全。

FAIL 可执行测试违反已定义的预期。

UNKNOWN 功能不可用、权限受限、未执行或缺少原生可信证据。

UA 声称 iPhone ≠ 真正的 iPhone；WebView 宣称新机型 ≠ 真实运行在对应系统；TLS/IP 由 Cloudflare 边缘观察，可能受到代理或 VPN 影响。
